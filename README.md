El presente proyecto es una Pagina Web para MANACO, donde podra ver todos los productos que ofrece MANACO.

## Accesibilidad (a11y)

Se implementaron las siguientes mejoras de accesibilidad:

- Se añadió un **skip link** para saltar directamente al contenido principal con teclado.  
- Se incluyó un **foco visible** en los enlaces para mejorar la navegación por teclado.  
- Todas las imágenes cuentan con un **atributo `alt` descriptivo**.  
- Se agregó **`aria-label` en la navegación principal** para mayor claridad en lectores de pantalla.  
- Se probó la navegación completa usando **teclado (tabulador y enter)**. 

## SEO

Se aplicaron las siguientes optimizaciones SEO:

- Se configuró un **`<title>` descriptivo**: "MANACO | Calzado de calidad para todos".  
- Se añadió una **meta description** de 155 caracteres con palabras clave relevantes.  
- Se incluyeron **etiquetas Open Graph (OG)** para optimizar la vista previa en redes sociales.  
- Se mantuvo una **jerarquía coherente de encabezados** (`h1` único, `h2` para secciones).  
- Se optimizaron imágenes con **atributos `alt`** descriptivos para indexación.
